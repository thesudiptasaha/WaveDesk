# Home page per user, compact rundown, script print layout (owner ideas, 2 Nov 2026) - discussion, nothing built

## Home page
- Each user type should have its OWN default home page (to be set later; people work differently).
- Idea: Home = a narrower, more COMPACT rundown plus a personal panel on its RIGHT with the user's own tasks (and work for today). Owner: this solves many problems.
- Rundown rows show round photos of the crew who matter to THIS viewer's role (different crew photos for different user types). Exact sets per role are still to be decided.

## Script print layout (decided direction)
- Credits tab = the DETAILED print (all credits, legal use).
- Script print = the script plus the essential information only:
  - START: writer, idea (concept creator), channel, date, time, ID, title - as it is now.
  - END: only a few core credits (the people who carry the content's rights/ownership; which roles is still to be settled). One name may stand under several credits.
- Page breaks: a black line shows where each page break falls (on screen, not on paper), so the number of printed pages is known before printing.
  - Technical note: the lines are produced with the same A4 size and margins as the print CSS, so they are very close but may differ slightly between browsers/printers. A generated PDF would be exact (credits PDF is already planned).
