> ⚠️ localhost ও লাইভ সাইট একই ডেটাবেস। SQL চালালে সঙ্গে সঙ্গে লাইভে কার্যকর। তাই SQL সবসময়: ছোট, যোগ-ভিত্তিক (additive), ফিরিয়ে নেওয়া যায় এমন, এবং আগে আমি পর্যালোচনা করে দেব।
 
## টেবিল
- **organizations**: id uuid(pk), name, owner_id, created_at.
- **team_members**: id uuid(pk), user_id, organization_id(fk, cascade), full_name, email, role (CHECK owner|manager|general), active, designation, avatar_url, auth_user_id, created_at, employee_id, phone, whatsapp, nickname; Access (৮টা bool, not null, ডিফল্ট false): can_write_edit_scripts, can_approve_scripts, can_edit_content_details, can_change_channel, can_reschedule_content, can_assign_video_editor, can_assign_presenter, can_review_videos; Roles (২১টা bool, ডিফল্ট false): role_concept_creator, role_research_script_writer, role_production_manager, role_producer, role_presenter, role_set_designer, role_camera_operator, role_teleprompter_operator, role_light_designer, role_sound_recordist, role_data_wrangler, role_makeup_artist, role_voice_over_artist, role_video_editor, role_motion_graphics_designer, role_graphic_designer, role_colorist, role_audio_mixer, role_publisher, role_live_video_switcher, role_live_audio_mixer. ইনডেক্স: org প্রতি একজন owner; (org, lower(email)) ইউনিক; auth_user_id ইউনিক; (org, lower(nickname)) ইউনিক।
- **team_members_legacy**: পুরনো, অব্যবহৃত বলে মনে হয়।
- **channels**: id **bigint**, name (**global UNIQUE(name)** + আলাদা UNIQUE(organization_id, lower(name))), created_at, organization_id(fk). কোনো code কলাম নেই।
- **contents**: id **bigint**, content_uid (ইউনিক, ট্রিগার `WAVECON-YYYYMMDD_XXXX`, তৈরির দিন, Asia/Dhaka; কাউন্টার `content_uid_counters: org_key, day, last_n` প্রতিদিন 0001 থেকে শুরু; ID কখনো পুনর্ব্যবহার হয় না; একবার বসলে পরিবর্তন করা যায় না — guard_contents_update checks WAVECON- prefix; শর্টস <content ID>-short_0001; ২৯ অক্টোবর ২০২৬ তারিখে `sql/2026-10-29_wavecon_content_id.sql` দিয়ে সব পুরনো CON- রূপান্তরিত), slug_name NN, title NN, status, previous_status, **channel text (নাম দিয়ে)**, content_type (CHECK EXPLAINER|LIVE|RECORDED LIVE|SOT|PACKAGE|SHOW), pipeline_type, scheduled_publish_time, published_at, went_live_at, target_platforms jsonb (default ["youtube","facebook"]), shorts/revisions/audit_log jsonb, short_days text[] (ট্রিগার), script, is_script_locked NN, thumbnail_text, post_caption, seo_keywords, hashtags, archive_shelf_id, raw_footage_link, project_file_url, live_video_url, master_export_url, hold/drop/reshoot_reason; ক্রেডিট text: writer, presenter_name, video_editor, camera_operator, concept_creator, producer, publisher, motion_graphics_designer, graphic_designer, voice_over_artist, colorist, light_designer, sound_recordist, teleprompter_operator, audio_mixer, live_video_switcher, live_audio_mixer, production_manager, set_designer, makeup_artist, data_wrangler; প্রকাশের ছাপ text: published_by (Publish ধাপে বসে); প্রোডাকশন কলাম: shoot_started_at timestamptz, shoot_finished_at timestamptz, production_notes text, files_delivered_at timestamptz, files_delivered_by text. ইনডেক্স: (organization_id, scheduled_publish_time)।
  - **পুরনো ডুপ্লিকেট কলাম (অ্যাপ ব্যবহার করে না):** writer_name, editor_name, script_body, raw_footage_url, presenter, script_locked।
- **notifications**: id bigint, organization_id, member_id(fk→team_members, cascade), content_id **text**, message, read, created_at; ইনডেক্স (member_id, created_at desc).
- **content_uid_counters**: UID কাউন্টার (`org_key, day, last_n`), `WAVECON-YYYYMMDD_XXXX`-এর জন্য প্রতিদিন 0001 থেকে কাউন্টার শুরু হয়; IDs are never reused; `content_counters` পুরনো কাউন্টার।

## RLS (সংক্ষেপে)
সব org-ভিত্তিক (`organization_id = my_org_id()`)। contents: select/insert/update `i_am_active()`, delete `is_manager()`। channels: insert/delete `is_manager()`। notifications: নিজের; delete নিজের বা manager। team_members: insert/delete manager (owner ছাড়া; manager তৈরি owner), update সব org-সদস্য (আসল সুরক্ষা ট্রিগারে)। organizations: শুধু select।
`is_manager()` = role owner|manager এবং active।
 
## ট্রিগার ও ফাংশন (বডি দেখা হয়েছে) — মূল তথ্য
- **contents_guard_update_production** (ট্রিগার ফাংশন `contents_production_rules`, রেকর্ড: `sql/2026-10-29_production_rules.sql`, `sql/2026-10-31_publisher_rule.sql`): Start Shoot ও Finish Shoot-এর অনুমতি যাচাই; Start Shoot-এ shoot_started_at ও ক্যামেরা অপারেটরের স্বয়ংক্রিয় টেকওভার; Finish Shoot-এ shoot_finished_at; হাতে শুট সময় পরিবর্তন পাহারা; প্রোডাকশন ক্রুর ১০ পদে এবং publisher ফিল্ডে প্রযোজক/ম্যানেজারদের কর্তৃত্ব ও অন্যদের সেলফ-অ্যাসাইন/রিমুভ সীমাবদ্ধতা (৩১ অক্টোবর রেকর্ড: `sql/2026-10-31_publisher_rule.sql`); Files delivered এককালীন টিক ও আনডু পাহারা।
- **contents_guard_update_production** (ট্রিগার ফাংশন `contents_production_rules`, রেকর্ড: `sql/2026-10-29_production_rules.sql`): Start Shoot ও Finish Shoot-এর অনুমতি যাচাই; Start Shoot-এ shoot_started_at ও ক্যামেরা অপারেটরের স্বয়ংক্রিয় টেকওভার; Finish Shoot-এ shoot_finished_at; হাতে শুট সময় পরিবর্তন পাহারা; প্রোডাকশন ক্রুর ১০ পদে প্রযোজক/ম্যানেজারদের কর্তৃত্ব ও অন্যদের সেলফ-অ্যাসাইন/রিমুভ সীমাবদ্ধতা; Files delivered এককালীন টিক ও আনডু পাহারা।
- **guard_contents_insert** (auth.uid() থাকলে): নতুন কনটেন্ট অবশ্যই status='Draft', published_at খালি।
- **guard_contents_update** (SQL Editor / auth.uid() null / `nw.bypass_guard`='1' হলে বাদ): অ্যাকটিভ সদস্য, একই org; WAVECON- প্রিফিক্সযুক্ত content_uid পরিবর্তন নিষেধ (the ID cannot change once set); script বদলাতে can_write_edit_scripts (লক থাকলে manager); `is_script_locked` শুধু manager; title/thumbnail_text/writer/archive_shelf_id/target_platforms/post_caption/seo_keywords/hashtags → can_edit_content_details; (camera_operator এখন contents_guard_update_production-এ নিয়ন্ত্রিত); channel → can_change_channel; scheduled_publish_time → can_reschedule_content; presenter_name → can_assign_presenter; video_editor → can_assign_video_editor; audit_log/revisions শুধু বাড়ে; published_at ও published_by শুধু Publish ধাপের সঙ্গে (বা manager) বদলায়; স্ট্যাটাস বদলের পুরো নিয়ম (কোন ধাপ কে করবে) এখানে: স্ক্রিপ্ট Submit → can_write_edit_scripts, অনুমোদন → can_approve_scripts, Editing-এ নেওয়া → can_assign_video_editor, Video Review-এর ফল → can_review_videos। **অন্যান্য অসুরক্ষিত ক্রেডিট কলাম (concept_creator, shorts, links ইত্যাদি) যেকোনো অ্যাকটিভ সদস্য বদলাতে পারে (১০টি ক্রু ফিল্ড ও publisher সুরক্ষিত)।** নতুন কলাম যোগ করলে ডিফল্টে অরক্ষিত — দরকারে guard-এ নিয়ম যোগ করতে হবে।
